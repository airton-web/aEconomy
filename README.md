# aEconomy

A multi-currency economy plugin (Paper) used by other plugins, like aSell.

> 🚧 Work in progress, created by [airton-web](https://github.com/airton-web)
> as part of my journey learning Java plugin development.

## Planned features

- Multiple currencies (coins and more)
- Balances saved to disk
- A simple API for other plugins to use
